# 🚗 Car Sales System

## 📌 Descrição
O Car Sales System é uma aplicação web desenvolvida para gestão de automóveis, permitindo adicionar, editar, listar e eliminar carros através de uma interface moderna estilo concessionária.



## 🏗️ Arquitetura do Sistema

O sistema segue uma arquitetura de três camadas:

- **Frontend:** Vue.js + HTML + CSS
- **Backend:** PHP (API REST)
- **Base de Dados:** MySQL / Neon DB



## ⚙️ Funcionalidades

- Login de administrador
- Dashboard com total de carros
- Adicionar carros
- Editar carros
- Eliminar carros
- Listagem dinâmica em tempo real
- Imagens automáticas baseadas na marca do carro



## ☁️ Deploy na Nuvem

O sistema está hospedado numa plataforma cloud gratuita.

🔗 **Link do sistema online:**
https://car-sales-system-api.onrender.com



🐳 Docker

O sistema foi containerizado utilizando Docker e Docker Compose para facilitar a execução em ambiente isolado.



🗄️ Base de Dados

Durante o desenvolvimento foi utilizada a plataforma **Neon**, devido a problemas iniciais de conexão com credenciais locais.
